# Animall Website

A **static React website** for Animall — the Marathi-first livestock marketplace PWA.

## Start here

**→ Read `V1-PLAN.md`. That's the whole plan.**

It covers: what we're building (7 static pages), the stack (Vite + React + Tailwind + react-snap), the home-page layout, the 10–14 day timeline, and the minimum you need to provide before we start.

## Status

- **Phase**: V1 planning complete. Awaiting "go" to scaffold the Vite app.
- **Pre-reqs to ship V1**: domain registered, Play Store status confirmed, logo + founder bios provided.
- **Target**: V1 live in 10–14 days of focused work.

## Why is there a `docs/future-reference/` folder?

The earlier plan was much broader — Next.js, programmatic city pages, a blog engine, a B2B funnel with CRM, multi-phase roadmap. That thinking is preserved in `docs/future-reference/` as the V2-and-beyond reference. **It is not what we're building now.** Come back to it after V1 ships and there's real traction data.

V1 is intentionally narrow: a beautiful, fast, static marketing site that drives app installs. Everything else can wait.
